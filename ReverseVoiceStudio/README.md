# Reverse Voice

Application Android hors ligne pour :

- importer ou enregistrer un son ;
- le lire à l’envers ;
- appliquer une voix grave, aiguë, robot ou un écho ;
- régler la vitesse ;
- écouter un aperçu et exporter le résultat en WAV.

Le traitement se fait localement dans l’application. Le projet se compile avec
la configuration Gradle incluse (Android SDK 35, Java 17).
